# Post dimostrativi del tema Mediumish

Questi 14 file NON sono contenuti del progetto BullismoOnline.

Sono i post di esempio del tema Jekyll [Mediumish](https://www.wowthemes.net) di
WowThemes.net, firmati `sal` e `john`, arrivati con il template alla migrazione da
WordPress a Jekyll (commit iniziale del 7 febbraio 2019).

Sono stati spostati fuori da `_posts/` l'11 agosto 2026 perché comparivano
nell'archivio pubblico insieme agli articoli veri, in inglese e senza alcun rapporto
con il tema del sito. La cartella inizia con un underscore, quindi Jekyll non la
compila: i file restano nel repository e nella storia git, ma non finiscono nel sito.

Non cancellarli: servono come riferimento se un giorno si tocca il tema.
